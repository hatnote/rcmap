Wikipedia Recent Changes Map

Recent Changes Map has been sunset. In November 2025, Wikipedia replaced anonymous IP-based editing with temporary accounts, removing the IP addresses that made geolocation possible. This is a positive change for editor privacy. Thanks for all the years of watching the map! For a live feed of Wikipedia edits, visit Listen to Wikipedia.

What is this map?

Read more about this project.

This map showed the approximate geographic location of unregistered Wikipedia editors, identified by their IP addresses. In November 2025, Wikipedia adopted temporary accounts for unregistered editors, replacing visible IP addresses with pseudonymous usernames. This change improves editor privacy but means geolocation of edits is no longer possible. The map is preserved here as an archive.

Built using d3 and DataMaps, with geolocation data from MaxMind GeoLite2 and the Wikimedia EventStreams feed, broadcast through wikimon. Source available on GitHub.

Built by Stephen LaPorte and Mahmoud Hashemi.
